# Прототип сайта «Игры Первых»

## Описание
Демонстрационный прототип сайта Всероссийского проекта «Игры Первых», разработанный в рамках конкурса по прикладному применению ИИ.

## Требования
- Современный браузер (Chrome, Firefox, Edge, Safari)
- Подключение к интернету для загрузки иконок, картинок

## Запуск
1. Распакуйте архив в любую папку.
2. Откройте файл `index.html` в браузере (двойной клик или через меню «Открыть файл»).
3. Сайт готов к работе.

## Переключение ролей
- В правом верхнем углу нажмите «Администратор» для управления контентом.
- Нажмите «Пользователь» для просмотра без прав редактирования.

## Реализованные функции
- Просмотр разделов: О проекте, Игровой процесс, Мероприятия, Новости, Библиотека, Обратная связь, Партнёры.
- Фильтрация и поиск мероприятий.
- Отправка отзывов (сохраняются в памяти сессии).
- Роль «Администратор»: добавление/редактирование/удаление мероприятий, новостей, материалов, партнёров.
- Ссылки на скачивание приложения (демо) и социальные сети.
- Адаптивный дизайн для мобильных устройств.

## Использованные технологии
- HTML5, CSS3, JavaScript (ES6)
- Шрифт Pervye Book
- Все данные вымышлены

## Ограничения демоверсии
- Данные не сохраняются после перезагрузки страницы.
- Отсутствует реальная авторизация (переключение ролей демонстрационное).
- Ссылки на приложение и соцсети ведут на заглушки (демо).
